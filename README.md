# موقع ريان الحربي الشخصي

بورتفوليو شخصي ومختبر مبسط لتجربة تطبيق Node.js قبل النشر السحابي.

## التشغيل المحلي

يتطلب Node.js 20 أو أحدث.

```powershell
node server.js
```

ثم افتح: `http://localhost:3000`

## ما الذي يحاكيه؟

- خادم Node.js قابل للنشر.
- فحص صحة للخدمة عبر `/health`.
- واجهة API تجريبية لتحليل نص سيرة ذاتية عبر `/api/resume-preview`.
- لا يحتفظ الخادم بالنصوص أو الملفات، ولا يستقبل ملفات PDF في هذه المرحلة.

## قبل النشر الفعلي

1. استبدل روابط LinkedIn وGitHub في `public/index.html` بروابطك الصحيحة.
2. راجع وصف المشاريع وأضف صورًا أو روابط أعمالك المعتمدة.
3. عند ربط تحليل سير حقيقي: أضف سياسة خصوصية، تخزينًا آمنًا، صلاحيات، وسجل تدقيق.
