# تقرير الفحص الأمني المحلي

**تاريخ الفحص:** 4 نوفمبر 2026
**النطاق:** الواجهة العامة، واجهات API، لوحة الإدارة، إعدادات المشروع وملفات Git الخاصة بالموقع الشخصي.

## النتيجة المختصرة

النسخة الحالية مناسبة للتطوير والاختبار المحلي بعد ربطها بقاعدة Neon. لم يظهر في المسح أي سر حقيقي أو رابط قاعدة بيانات أو مفتاح API ضمن الملفات المتعقبة. مسار الإدارة محمي على مستوى الخادم، ولا يعتمد على إخفاء الواجهة فقط.

لا تعد هذه النتيجة اعتمادًا للنشر العام قبل استكمال إعدادات Google OAuth وبيئة الاستضافة وHTTPS.

## ما تم التحقق منه

| المجال | النتيجة |
| --- | --- |
| أسرار المشروع | لا توجد كلمات مرور أو روابط اتصال أو مفاتيح حية في الملفات المتعقبة. ملفات الإعدادات المحلية مستثناة من Git. |
| لوحة الإدارة | طلبات الإدارة غير المصرح بها تعيد `401`، وصفحات ولوحات الإدارة تستخدم ترويسات تمنع التخزين المؤقت. |
| حماية المتصفح | ترويسات `CSP` و`X-Frame-Options` و`X-Content-Type-Options` و`Referrer-Policy` و`Permissions-Policy` مفعلة. |
| التعامل مع المحتوى | لا يستخدم المشروع `innerHTML` أو `document.write` أو `eval` أو إنشاء دوال ديناميكية في المسارات التي تم فحصها. |
| قاعدة البيانات | الاتصال يستخدم PostgreSQL عبر EF Core مع إعادة محاولة محدودة للأخطاء العابرة. |
| الحزم المعتمدة | فحص حزم .NET لم يبدِ حزمًا ذات ثغرات معروفة من مصادر NuGet الحالية. |
| الملفات الحساسة | لا يمكن الوصول إلى ملفات الإعدادات المحلية أو مسارات المصدر كملفات ثابتة عبر الخادم. |

## تحسينات طبقت أثناء الفحص

1. منع تخزين صفحات الإدارة وواجهات الإدارة وواجهات الدخول في ذاكرة المتصفح أو الوسيط.
2. إضافة إعادة محاولة محدودة وآمنة لاتصال قاعدة البيانات عند وقوع انقطاع مؤقت.
3. تثبيت الواجهة العامة على بيانات احتياطية ثنائية اللغة لتفادي ظهور بيانات غير مكتملة أثناء انتظار الاستجابة.
4. فصل خادم Node.js القديم عن مسار التشغيل الافتراضي؛ مسار الإنتاج المعتمد هو ASP.NET Core فقط.

## أمور مطلوبة قبل النشر العام

1. إنشاء تطبيق Google OAuth وتخزين معرفه وسره في إعدادات الخادم أو منصة الاستضافة فقط، مع تسجيل عنوان العودة الخاص بالنطاق الفعلي.
2. تحديد البريد أو الحسابات المصرح لها بإدارة المحتوى في إعدادات الخادم، وليس في ملفات الواجهة.
3. النشر عبر HTTPS وربط نطاق موثوق. يفعّل الخادم HSTS في بيئة الإنتاج فقط.
4. عند إضافة Gemini أو أي خدمة ذكاء اصطناعي، يحفظ مفتاحها في الخادم فقط ولا يرسل للمتصفح.
5. عند تنفيذ رفع الصور أو الشهادات، يستخدم الخادم تخزينًا خاصًا ومدارًا ويعيد روابط وصول مصرح بها؛ لا توضع الملفات الحساسة داخل `public`.

## عناصر مؤجلة لا تعيق النسخة الحالية

- تسجيل دخول Google الفعلي ينتظر بيانات OAuth من حساب المالك.
- الذكاء الاصطناعي لاقتراح النصوص والترجمة لم يُفعل بعد؛ الواجهة والبيانات تدعمان العربية والإنجليزية يدويًا.
- خادم Node.js القديم غير معتمد للنشر. لا يلزم فحص حزم Node أو تشغيله ما لم يُتخذ قرار بالعودة إليه.

## طريقة إعادة الفحص

بعد أي تغيير جوهري، شغل بناء الحل ثم تحقق من صفحة الصحة وطلب غير مصرح به لمسار الإدارة. قبل النشر، راجع إعدادات البيئة في منصة الاستضافة وتأكد أن الملفات السرية لا تظهر في Git أو في ملفات الواجهة.
