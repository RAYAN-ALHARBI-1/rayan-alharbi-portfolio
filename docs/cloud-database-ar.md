# ربط قاعدة بيانات PostgreSQL سحابية

## ما الذي ينجزه هذا المسار؟

يجعل الموقع يعمل بقاعدة بيانات حقيقية دون Docker أو WSL أو أي قاعدة تعمل على جهازك. يبقى رابط الاتصال خارج Git، وتقرأه الاستضافة لاحقًا من إعداداتها الخاصة.

## قبل البدء

1. أنشئ قاعدة PostgreSQL مُدارة لدى المزود الذي تختاره.
2. انسخ رابط الاتصال الكامل من لوحة المزود.
3. لا تضع الرابط في Git أو ملف JavaScript أو رسالة عامة؛ فهو غالبًا يتضمن كلمة مرور قاعدة البيانات.

يمكن اختيار مزود مجاني كبداية، ثم نقله لاحقًا إلى مزود الإنتاج دون تغيير الواجهة أو مخطط الجداول.

## الإعداد على جهازك

من جذر المشروع شغّل:

```powershell
.\scripts\connect-cloud-database.ps1
```

سيطلب السكربت الرابط دون إظهاره أثناء الكتابة، ثم يقوم بالآتي:

1. يحفظه محليًا في .NET User Secrets خارج ملفات المشروع.
2. ينفذ ترحيلات EF Core لإنشاء الجداول.
3. يضيف بيانات الملف الشخصي والمشاريع والشهادات مرة واحدة فقط إذا كانت غير موجودة.

لا يحذف السكربت أي سجل موجود ولا يستبدل تعديلاتك في لوحة الإدارة.

## تشغيل الموقع بعد الربط

```powershell
.\scripts\run-server.ps1
```

ثم افتح:

```text
http://127.0.0.1:5088/portfolio.html
```

يمكن فحص الاتصال من:

```text
http://127.0.0.1:5088/health
```

## عند النشر

ضع الرابط نفسه في إعدادات الاستضافة باسم:

```text
ConnectionStrings__PortfolioDb
```

لا تنسخ ملف User Secrets ولا أي كلمة مرور إلى المستودع. تُنفذ الترحيلات من بيئة النشر أو خطوة نشر موثوقة، ثم يبقى الخادم هو الجهة الوحيدة التي تتصل بقاعدة البيانات.
