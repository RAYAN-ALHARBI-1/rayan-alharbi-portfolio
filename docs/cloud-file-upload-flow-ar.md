# مسار رفع الملفات الآمن

هذه الوثيقة تشرح آلية الرفع التي يمكن إضافتها مستقبلًا، مثل إرفاق ملف مشروع في نموذج التواصل. لا يوجد رفع ملفات مفعل في الموقع الآن.

## المسار

1. يسجل المستخدم دخوله إذا كانت الميزة تتطلب حسابًا.
2. يرسل المتصفح طلبًا إلى الـAPI للحصول على إذن رفع محدود للملف.
3. يتحقق الـAPI من الصلاحية، نوع الملف، الحجم، وعدد الملفات المسموح بها.
4. ينشئ الخادم رابط رفع مؤقتًا إلى التخزين السحابي الخاص.
5. يرفع المتصفح الملف عبر HTTPS مباشرة إلى التخزين؛ لا يمر الملف عبر الواجهة ولا يوضع في قاعدة البيانات.
6. يسجل الـAPI بيانات الملف فقط: المالك، الاسم الآمن، النوع، الحجم، ومعرّف التخزين.
7. عند المعاينة أو التنزيل، يتحقق الـAPI من الصلاحية ثم يعيد رابط تنزيل مؤقتًا أو يمرر الملف بشكل آمن.

## ضوابط الحماية

- الملفات خاصة افتراضيًا؛ لا توجد روابط عامة دائمة.
- روابط الرفع والتنزيل قصيرة الصلاحية ومقيدة بالعملية المطلوبة.
- التحقق الحقيقي من النوع والحجم والصلاحية يكون في الخادم، لا في المتصفح فقط.
- فحص الملفات، حدود المعدل، وسجل تدقيق تضاف قبل استقبال ملفات حساسة مثل السير الذاتية.
- لا تحفظ مفاتيح التخزين أو كلمات المرور داخل JavaScript أو Git.
